# 喜茶拙趣体

为用户给定的文字逐笔绘制矢量字形，交付独立、可编辑的 `.svg`。风格核心是**保留结构关系的字内比例失衡**：依据部件的作用安排收紧与伸展；偏旁靠拢，笔画保持干净等粗。

## 先看结构

首次绘制时查看 [结构参考图](references/structure-reference.png)，并阅读 [示例说明](references/examples.md)。参考图只提供字形和笔形信息，不是要复制的文案。用户要求的新文字必须准确呈现。

已确认的三个词保存在 `assets/examples/`，同时提供绘图 JSON 和最终 SVG。参照这些轮廓、部件间距和分组方式；旧样例的细线不代表当前默认粗细。多字或多行构图时阅读 [粗细与排版参考](references/composition.md)，查看其中的用户参考图。新字需要重新设计路径，不能靠把普通字体拉伸、倾斜或转成轮廓来代替设计。

## 字结构变形强度

设计参数 `deformation_strength`（字结构变形强度）接受 **低／中／高** 三档，默认 **高**。用户可直接说“低强度”“变形强度中”或“高强度”；新作品未指定时直接使用高档，无须询问。该参数用于绘制路径前的结构设计，不是对成品 SVG 做统一缩放。

| 强度 | 字内结构的处理 |
| --- | --- |
| 低 | 保留接近常规的部件比例，选择一个局部做克制但可辨的伸长、收紧或重心偏移，内部空间相对均衡。 |
| 中 | 明显拉开主次部件的比例，选择一两个主导形变，让伸展与收紧形成清楚反差，仍保留较熟悉的整体骨架。 |
| 高（默认） | 在保留部件间结构关系的前提下，大幅强化一两个主导形变：可伸展的部件充分伸展，可收紧的局部明显收紧，重心与留白有意失衡。单看字形就应有鲜明的比例反差，不能只靠整字错落或倾斜表现强度。 |

三档都遵守下方字形规则：先保留部件间的结构关系，再确定形变方向，最后控制幅度。结构关系优先于强度；承担覆盖、包围或承托作用的部件，不能仅因笔画少或被视为“次部件”就缩小。例如“县”上部始终保留纵势，由低到高逐步加强窄长比例及其与下部的反差，不能在高档改成横向压扁。提高强度不改变笔画数量、连接关系和辨识特征，也不改变线宽、长横浅折概率或用户指定的排版；不要求每个部件同时变形。

修改已有作品时沿用原强度；只有用户要求调整强度或重新设计时才改变。强度调整应保留文字、既定排版、线宽和随机种子。

## 字形规则

- **夸张发生在字内部。** 仅让整字大小不同、旋转或上下跳动仍会太规整。先分解偏旁及笔画组，再改变各部分的宽高和视觉重量。
- **部件不能脱离整字关系独立变形。** 先辨认哪些部件覆盖、包围、承托或贯穿其他部件，再确定可变的尺寸与位置。变形后仍须一眼看出原有关系，不能只保证各部件单独可辨；高强度也不能以破坏结构关系换取比例反差。
- **承担结构作用的部件，应随其作用对象联动调整。** 覆盖部件应在视觉上罩住下部主体；包围部件应维持内外关系及原有开口；承托部件应托住上部重心；贯穿笔画应保留对相关笔画组的联系。按具体字判断这些作用，不把所有上部都当作盖子，也不机械要求所有底部都最宽。例如“家”的宝盖头承担覆盖作用，应横向舒展、覆盖下部主体的横向范围，不能缩成悬在宽大下部之上的小帽子。下部展开时应同步调整宝盖头的跨度、位置与间距；若要制造反差，可压低宝盖头的高度、收小顶点或伸长下部，而不能丢失覆盖感。
- **先判断结构，再选择形变方向。** 每字选一两个主导形变，保留其余识别特征。依据部件的纵横骨架、内部笔画层次及其在整字中的作用，决定横向展开、纵向拉长或局部缩小；不要见到方框就横向压扁。
- **纵向叠横的结构应保留并强化纵势。** “目”“且”及“县”上部这类由竖向骨架串起多层横画的结构，应纵向拉长，给各层横画留出清楚的上下间隔，不能套用扁口／扁日框的横向拉伸。以“县”为例，上部应窄长，下部“厶”另行安排宽度与重心，不把上部画成扁宽的多层横框。
- 横向拉宽只用于适合横向展开的部件。已确认样例中“喝”的小口旁、“早”的日部采用扁框，是针对这些字的局部设计，不是所有口、日、目形部件的通则。其他字可通过缩小偏旁、伸长竖钩或展开撇捺形成比例反差。
- 部件大小差异由整字结构决定，不预设统一的宽度或占地倍数。主导部件可以明显伸展，次要部件可以收紧，但不能为了比例反差压坏内部层次；避免所有部件等大、等宽、居中对齐。
- 结构松散、线条略带自然弯曲，但不加毛边、颗粒、笔刷宽度变化、描边噪声或重复抖动。圆头圆角，浅折处仍能看见转向。
- **偏旁靠拢，字形不缩回常规比例。** 小口旁靠近右侧，小木旁靠近“不”，提手靠近长钩。必要时按整体平移一个偏旁，保留它内部每条路径的形状。部件外接框可以在不同高度交错，实际笔画不能意外相交。
- 参考的紧凑间距是几倍线宽；极小部件之间留清楚的缝隙。不要用统一加大字距来制造“手写感”。

## 排版自由度

设计参数 `layout_freedom`（排版自由度）接受 **低／中／高** 三档，默认 **高**，与 `deformation_strength` 独立。用户可说“变形高、排版中”或“排版自由度高”。提高排版自由度不改变文字、指定分行或画幅比例，也不自动改变字内结构强度和线宽。

| 自由度 | 字与字、行与行的组织 |
| --- | --- |
| 低 | 阅读行清楚，保留适度大小差、自然字距和少量基线偏移，不强行统一字框和笔画角度。 |
| 中 | 明显改变相邻字的宽高、基线和间距，局部形成疏密组，行首行尾适当错开。 |
| 高（默认） | 依字形安排高低、大小、宽窄和方向，利用相邻字的空处嵌入，形成不对称的词组轮廓；行内不共用整齐顶线／底线，行间不形成等宽等高的字列。仍保持明确的阅读顺序。 |

- **先设计词组轮廓，再放字。** 避免先排等距网格再加轻微上下抖动。相邻字的可见边界、重心和留白决定位置；宽字旁可接小字，长钩旁可接抬高的字，疏密不必均匀。不要把每字固定在相近宽高的长方框里。
- **错落不是整行倾斜，也不是交替高低。** 混合字宽、字高、基线、留白与局部方向的变化；不要用相同的旋转、缩放或周期性偏移套整行。大小变化不改变线宽。实际笔画不能因嵌让而碰撞。
- 用户指定三行，只约束三组文字的阅读层级，不意味着三条直基线、五列对齐或等行距。各行的起止位置、宽度、疏密和轮廓按内容单独设计；指定横排、竖排、分行和画幅比例均须保留。附带拉丁字母也需手绘，字高与底线可自然变化。
- 将成稿缩小看整体：如果仍能明显看出整齐的行列格子，或只是每个字略有倾斜，则高自由度尚未达标。参考图中的布局是疏密与轮廓的关系，不是要照搬其字数或换行。

## 笔画姿态与线条

- **横竖不能全部趋向同一个角度。** 不把所有横画写成相同的右上斜线，也不让所有竖画沿相同斜率或同样弯曲。按字结构分别安排平、微上扬、微下落的横画，以及直立、内收、外展的竖画；相邻字可有不同的轴向。框的上下边与左右边也不必机械平行，但连接和包围关系要成立。
- 姿态变化来自有意选择的笔画组与字势，不给每个点随机扰动，不以重复抖动、统一斜切或整字旋转代替笔画设计。减少整齐感后仍保留平滑、等粗、圆头圆角的线条。
- 默认用 `viewBox="0 0 640 480"`、深色墨线 `#34332f`、`stroke-width="6.2"`、`fill="none"`。这是主字高度约 180–240 设计单位时的粗实线宽；画布可按构图调整。设计坐标整体改变时同步换算线宽，不因画布变大就沿用过细的绝对值。按参考图检查视觉重量，常见主字的线宽约为其高度的 2.5%–4%，不以极端伸长笔画作为唯一基准。
- 一张作品的每一笔都使用同一线宽，包括大字、小字和数字。设计大小差异时直接改变坐标，不用会改变局部线宽的缩放。
- 加粗后重新检查小部件的负形和笔画间隙；若挤塞，扩大局部空间或联动移动部件，不能通过减细局部笔画解决。旧稿未要求改粗时保留原线宽。
- 默认透明底，预览可使用白色或浅暖白底。需要纯色背景时才将背景写入 SVG。

## 长横的随机浅折

- 每条合适的长横**独立以 60% 概率**触发；不是强制每幅恰好有 60%，也不是整幅只抽取一次。
- 从视觉左端起约 24%–34% 处向下浅折一次，再向右平缓抬起，接近参考图的“左端略下沉，后段舒展”。不要做成多次锯齿或波浪。
- 浅折深度约为横长的 6.5%–9%。紧邻其他横画的扁框或日部需减小幅度，避免碰线；必要时明确排除该笔。
- 保留原横画两端及后续钩折，仅替换横画部分。线宽始终不变。
- 固定一次随机种子，定稿 SVG 中固化路径。调整间距或再次渲染时沿用种子；用户要求换一版时才重新随机。不要把脚本或运行时随机逻辑嵌入交付的 SVG。

## 制作与交付

1. 确认准确文案、画幅／分行、字结构变形强度与排版自由度（两项新作均默认高），先辨认并保留部件间的结构关系，再分别设计字内比例和词组轮廓。信息足够时直接绘制。
2. 直接写 SVG 路径，或按 [绘图数据格式](references/drawing-format.md) 写 JSON，调用 `scripts/render_svg.py` 统一导出及应用浅折。工具仅处理已设计的路径，不会从任意文字自动得到字形。
3. 保留以字为单位的 `<g data-character="…">` 分组；需要缩小部件间隙时用局部平移。使用开放的中心线 `<path>`；不使用 `<text>`、字体依赖、嵌入位图或描摹图片毛边。
4. 先检查整字结构关系：盖是否仍罩住主体、包围是否仍成立、承托是否仍稳住重心、贯穿是否仍保持联系；发现关系失效时联动调整相关部件，不能以“仍能认出字”为由通过。再检查文字没有缺笔、字内比例与所选强度一致，粗细接近参考、小部件不糊，横竖姿态不过度同向。最后缩小检查整幅：字间有大小疏密变化，没有不必要的齐顶齐底或跨行对列，符合排版自由度；指定画幅与分行正确，所有笔画在画布内。可用现有 SVG 预览或浏览器查看；不为生成 SVG 自动建站、发布或启动服务器。
5. 交付 `.svg` 文件链接；有可用预览时展示它。绘图 JSON 可随文件保存以便修改，但不能用 JSON、PNG 或 HTML 替代 SVG。用户要求网页预览时才增加本地预览。

修改已确认作品时，只调整用户要求的维度。例如“更紧凑”只移动部件，不重新设计字形、线宽、排版和随机结果。
