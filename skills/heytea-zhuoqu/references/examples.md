# 已确认的结构与间距

这些样例来自用户逐步确认的矢量稿。优先学习部件的比例关系；目标是生成新的字，而非从参考图片中抽取文字。

这些旧稿保留原线宽，不是当前默认粗细的模板。新作的粗细与多字构图参照 [粗细与排版参考](composition.md)。

- [散步](../assets/examples/sanbu.svg) / [绘图数据](../assets/examples/sanbu.json)：散的左下部被压扁拉宽，右侧撇捺放大；步的上半部缩小聚集，下方长撇大幅舒展。两字沿斜向展开。
- [喝8杯水](../assets/examples/heshui.svg) / [绘图数据](../assets/examples/heshui.json)：喝的口旁是扁小框，靠近右部；右侧大钩包围明显留白。数字 8 上小下大。杯的木旁小、不部宽大。水的主钩长，侧笔收紧。
- [早起打卡](../assets/examples/zaoqi.svg) / [绘图数据](../assets/examples/zaoqi.json)：早的日部极扁极宽，下面十部窄长；起的己部横向撑开；打的提手小而靠拢，丁的主钩异常长；卡的上部缩在长横右侧。

判断风格是否到位：遮住排版，只看单个字，它本身是否仍有明显的夸张比例？若只是整字错落或轻微倾斜，需要重新设计字内部件。

保持字形时，应平移完整的偏旁或笔画组，而不压缩整字。示例 JSON 的 `translate` 保留了最后确认的紧凑间距。

`structure-reference.png` 中的参考文字呈现了关键比例：细小上部与极扁长框、压缩的小偏旁与大幅伸展的长钩。图片中的粗糙边缘和宽度变化不是本技能需要复现的特征。
