# SVG 绘图工具

`scripts/render_svg.py` 只依赖 Python 标准库。模型负责设计新字的笔画，脚本负责输出、线宽统一、随机浅折及字符顺序检查。示例数据在 `assets/examples/`。

```sh
python3 <技能目录>/scripts/render_svg.py drawing.json --out lettering.svg
```

输入示意（此片段只展示数据结构，完整字形应参考随技能保存的 JSON）：

```json
{
  "text": "一",
  "viewBox": [0, 0, 640, 480],
  "stroke_width": 6.2,
  "deformation_strength": "高",
  "layout_freedom": "高",
  "color": "#34332f",
  "seed": 42,
  "glyphs": [
    {
      "char": "一",
      "at": [160, 190],
      "strokes": [{"d": "M0 57 Q61 55 117 53 Q184 48 252 49"}]
    }
  ]
}
```

- `text` 为准确文案；`glyphs` 按阅读顺序排列，`char` 与文案对应。数字同样需要设计路径。
- `deformation_strength` 与 `layout_freedom` 均接受 `低`、`中`、`高`，默认 `高`。脚本校验并记录这两个设计参数，但不会自动设计字形、随机挪字或排网格；需要在绘制路径和安排 `at` 时实现它们。
- `stroke_width` 默认 `6.2`；适用于常见主字高约 180–240 设计单位。大字、小字共用同一线宽，旧稿显式记录的原线宽会保留。
- `at` 只定位整字；每条笔画还可有 `translate: [30, 0]`，用于移动偏旁而保留内部形状。移动完整偏旁时给它的所有笔画相同平移量。
- `strokes` 可包含路径字符串，或包含 `d`、`translate`、`fold` 的对象。
- `d` 支持绝对坐标 `M/L/Q/C/Z`，每段显式写命令，不省略重复命令。多笔可用多个 `M`，建议分开便于编辑。工具拒绝含相对命令或未知语法的路径。
- `fold` 默认启用。扁框内紧邻的横画可用 `"fold": {"max_depth": 4}` 限制折深；希望保留形状的笔画用 `"fold": false`。
- `long_horizontal_min` 默认为 80 设计单位。脚本只识别每个 `M` 后起始的、向右、近平的连续 `L/Q` 段；过短或斜率太大的线不会触发。若希望一条复合笔画中间的长横参与随机，把该横拆成以 `M` 开始的路径，保持接点一致。
- 同一条长横只能产生一次浅折。后续竖画和钩不参与；相交连接是否合理仍需视觉检查。
- `background` 可选，默认无背景。所有笔画共用一个线宽，平移不会改变它。

## 随机与修改

`seed` 确定每条长横的独立 60% 抽样、折点位置和折深。未提供时工具生成随机种子，并在命令输出和 SVG 根节点 `data-seed` 中保存。将该种子写回工作 JSON，后续修改沿用它。

只改 `translate` 或 `at` 不会改变随机结果。工具对每条候选长横固定消耗三个随机数，不因是否启用浅折而改变后续笔画的抽样。若增删或重排笔画可能改变后续抽样；局部改稿时优先保留已有最终路径。

用户要求换一版时使用新的 `--seed`，并将新种子记录到工作 JSON。最终 SVG 没有 JavaScript、外部字体或图片，下载、预览和导入设计软件都会保持同一字形。

## 示例再生成

```sh
python3 <技能目录>/scripts/render_svg.py <技能目录>/assets/examples/heshui.json --out heshui.svg
```

不要以示例文本作为新请求的默认输出。生成“跑步”时，需要设计“跑”的新路径；不能只改 SVG 的标题或标签。
